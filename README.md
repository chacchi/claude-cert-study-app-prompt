# claude-cert-study-app-prompt

Claude 認定資格（CCAO-F / CCDV-F）の学習アプリを、AI アシスタント（Muse）に作ってもらうための共有プロンプト集です。

## これは何？

進捗を保存できる学習アプリは共有リンクでは渡せないため、アプリそのものではなく「同じアプリを再現するためのプロンプト」を公開しています。プロンプトを自分の AI アシスタントに渡すと、練習問題・単語クイズ・学習スケジュールを備えた学習アプリを生成できます。

## 使い方

1. `claude-cert-study-app-prompt.md` を開く
2. 「プロンプト本文」のコードブロックを丸ごとコピーする
3. 自分の AI アシスタント（Muse など）に貼り付けて送信する
4. 生成されたアプリで学習を開始する。生成後に確認したいポイントは同ファイル末尾のチェックリストを参照

## 注意事項

- このプロンプトは、2026年12月7日の出題内容更新より前の試験ガイド（v1.0）に基づく仕様です。12月7日以降に受験する場合は、最新の公式ガイドと照らし合わせて調整してください。
- 練習問題は公式ガイドの出題範囲に基づいて作成されるオリジナル問題です。本番試験の問題そのものは含まれていません。
- 生成する AI ごとに問題文の細部は変わるため、完全に同一のアプリにはなりません。
